## Context

Владелец подключил платный ключ Gemini 2026-08-05. Локальные прогоны
eval-корпуса шли на `60` запросах в минуту для быстрой модели и `30` для
тяжёлой — семь прогонов, примерно по 140 запросов к провайдеру, ни одного отказа
по квоте. На Render при этом остались `14` и `4`, выведенные из free tier
(15 RPM для `gemini-3.5-flash-lite`, 5 RPM для `gemini-3.5-flash`).

Сон инстанса — не только холодный старт. Долговременные задания забирает сам
Python-сервис, опрашивая Core (`/api/ai-analysis-runs/claim`); Core в эту
сторону ничего не шлёт. Собственный опрос — исходящий трафик и таймер сна не
сбрасывает, поэтому спящий инстанс не забирает задания вообще, а не забирает их
медленно.

## Decisions made

- Десять минут, а не пятнадцать: планировщик GitHub регулярно опаздывает на
  несколько минут, и пятнадцатиминутный период уезжал бы за окно сна.
- Будильник, а не платный план: рабочий обход без трат. Цена обхода записана —
  free-план даёт 750 инстанс-часов в месяц при 730 часах в месяце, то есть
  постоянно бодрствующий сервис съедает весь бесплатный запас аккаунта.
- `60`/`30` взяты из измеренного прогона, а не из таблицы лимитов платного
  тарифа: это те числа, которые реально прошли.

## Assumptions

- На дашборде Render в `GEMINI_API_KEY` лежит тот же платный ключ, что
  использовался локально. Проверить это агент не может — значение секрета не
  читается. Если ключ там старый бесплатный, `60` даст `429` почти на каждой
  отправке; транспорт повторяет их по `Retry-After`, поэтому раунд поползёт, а
  не упадёт, и чинить надо ключ, а не число.
