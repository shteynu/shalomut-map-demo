## Objective

Починить дефект транспорта: при отказе по содержанию повторная попытка
пересылала тот же самый запрос. Дать вызывающей стороне возможность сказать
следующей попытке, что именно исправить.

## User-visible outcome

Никакого — сегодня. Промпты байт в байт те же, ни один вызов не передаёт
критику, поведение раунда не меняется. Смысл правки в том, что следующая
проверка, которая захочет отказать по содержанию, сможет чинить текст, а не
выбрасывать его.

## Context

Запрос собирался один раз выше цикла попыток, поэтому вторая попытка была
буквально первой ещё раз. Пока отказы были только по форме — обрыв, латиница,
неверный JSON — это почти не мешало: пересэмплирование их чинит. Как только
появился отказ по содержанию, дефект стал стоить дорого: измерено на
eval-корпусе 2026-08-05 в ветке `fix/refuse-asserted-causes` — отказанная
фраза возвращалась трижды, и 22 измерения из 56 остались без текста от модели.
Само то правило решено не вливать, а эту правку — вливать.

## Scope

- `complete_with_retries` собирает запрос на каждую попытку и принимает
  необязательный `critique_for`.
- `build_prompt` получает критику аргументом; все семь вызовов обновлены.
- `_joined_critique` складывает критику от переигровки измерения с критикой от
  повторной попытки: они про разные попытки и обе верны.
- Лог повторной попытки говорит `critique=yes|no`.

## Non-goals

- Причинностное правило и любой другой новый отказ. Здесь только механизм.
- Подключение `critique_for` к какому-либо вызову. Первый потребитель —
  отдельное решение, см. вопросы ниже.

## Acceptance criteria

- При отказе с критикой второй запрос отличается от первого ровно на неё.
- Без критики и при критике `None` второй запрос совпадает с первым.
- Весь Python-набор проходит.

## Decisions made

- `critique_for` необязателен, и без него повторная попытка остаётся ровно
  тем, чем была. Это то, что делает правку безопасной для вливания без
  измерения: сегодня она не меняет ни одного отправленного запроса.
- Критика не подключена ни к одному вызову. Подключать её к отказам по форме
  без измерения — значит менять текст промпта вслепую.
