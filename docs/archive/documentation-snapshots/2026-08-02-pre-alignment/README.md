# Documentation snapshot before the 2026-08-02 alignment

This directory preserves historical material removed when living documentation
was compacted and aligned in commit `238fe1d`. The payload files are exact
copies from its parent commit, `278ba9b`.

These files are historical evidence, not current instructions or sources of
truth. Commands, test counts, contract status, environment names and next steps
inside them may be obsolete. Use [`../../../README.md`](../../../README.md) to
find the corresponding living document.

## Snapshot contents

- [`PROGRESS.md.txt`](PROGRESS.md.txt) — detailed progress/session history.
- [`PROJECT_CONTEXT.md.txt`](PROJECT_CONTEXT.md.txt) — pre-compaction project
  context.
- [`ROADMAP.md.txt`](ROADMAP.md.txt) — roadmap before the alignment rewrite.
- [`docs/ai-analytics-handoff.md.txt`](docs/ai-analytics-handoff.md.txt) — old AI
  handoff snapshot.
- [`docs/shalomut-tracker-handoff.md.txt`](docs/shalomut-tracker-handoff.md.txt)
  — old operational/session handoff snapshot.

The `.md.txt` suffix is intentional: it keeps the contents byte-for-byte
recoverable while preventing old relative Markdown links and guidance from
being treated as current documentation.
